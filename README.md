# Val

> An open-source AI companion for conversations, ideas, and everything in between.

Val is a simple AI companion built for natural, casual conversations.

You can talk to Val about your day, share what's on your mind, brainstorm ideas, ask questions, or just have a conversation.

The idea behind Val is simple:

**Val doesn't always need to solve the problem. Sometimes, Val just needs to listen.**

## Features

* Natural and casual AI conversations
* Brainstorming and idea exploration
* Streaming responses
* Responsive interface
* New conversation support
* Copy and regenerate responses
* Minimal, dark-themed UI
* Lightweight single-file frontend

## Built With

* HTML
* CSS
* JavaScript
* Groq / OpenAI-compatible API

## Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/val.git
cd val
```

Then open `index.html` in your browser.

### API Configuration

For security reasons, never put an API key directly inside `index.html` or any other publicly accessible frontend file.

For a production setup, route API requests through a backend and store your key as an environment variable:

```env
GROQ_API_KEY=your_api_key_here
```

The current version is intended to be a lightweight prototype and starting point for building Val further.
